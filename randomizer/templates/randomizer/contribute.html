Contribute to SMRPG Randomizer

Want to help make SMRPG Randomizer even better? There are lots of ways you can do that!

The Easy Stuff

You don't need to be a software engineer to contribute to the randomizer! The project is always accepting submissions for:

  • Dr. Topper quiz questions
  • Star Hill wish text
  • Sunken Ship passwords
  • Melody Bay tunes
  • Palette swaps for the 5 main characters
  • Where to hide the Three Musty Fears' invisible items
  • Flag presets
  • Feature ideas in general

Tell us about your great idea over on GitHub! You can click the "New issue" button to fill out a form to submit any of these things (in plain English, no coding knowledge required).

(Note: custom player sprites à la Link in ALTTP are not being accepted at this time as such a subsitution mechanism has not been implemented, though it may be on the radar in the future.)

QA

SMRPG Randomizer is not recruiting QA testers at this time. If this changes, it will be announced on Twitter, Bluesky, and Reddit.

Please do not approach individual devs to request early access to new features, as much as the enthusiasm is appreciated.

Contribute Code

On the other hand, if you are an experienced or aspiring developer, great news: SMRPG Randomizer is 100% open source! You can submit pull requests on GitHub and browse the Issues section if you're looking for something to work on. (If you're a beginner, look for a "Good First Issue" tag!)

You do not need to know any assembly to contribute to SMRPG Randomizer. The vast majority of logic behind the things that happen in SMRPG's world is controlled through the game's own internal scripting system, which developers have full control over using only Python via the SMRPG Patch Builder library.

Some examples of things you can do without knowing any ASM:

  • Add a new item check
  • Change how an object or NPC in a room behaves (how it moves, how it animates, how it collides, etc)
  • Change the stats and other properties of allies, items, enemies, attacks, and spells
  • Change which rooms exit to which other rooms
  • Decide which boss fight is going to show up where
  • Add a new option for gating a world area
  • Create a new sprite animation for any character or object
  • Insert new NPCs and objects into rooms and move them around
  • Change how a monster behaves in battle
  • Add a new interaction that happens when you step on a certain tile
  • Invent new items
  • Change any dialog

If you've never attempted modding SMRPG before, it is strongly recommended that you download the Lazy Shell editor and have a look around at what you can do. The SMRPG Patch Builder library that forms the foundation of this randomizer is designed as an approximation to the Lazy Shell UI, letting you do things like add/remove/edit commands in scripts, modify the stats of certain entities, change dialogs, replace objects in world areas, etc, so having some familiarity with how these things work under the hood will help you develop features. You can do things like compare a script in Lazy Shell to its equivalent in the randomizer codebase to get an idea of how you can interact with these things as a developer.

Now of course, if you are comfortable working with 65C816 ASM, you can go even further with contributing features! Some things you could do with that include:

  • Changing the damage formula
  • Changing special behaviour of an accessory, such as the Coin Trick or EXP Booster (not Jump Shoes, though, that's script-controlled)
  • Implementing a "true" Shopsanity, where shops other than the Frog Disciple shop can hold some one-time purchases
  • Changing the speed at which dialogs are displayed
  • Allowing the ROM to have more than 256 VRAM partitions
  • Moving data around to make room for other data
  • Expanding the space available for battle animations (therefore giving us more space for battle animation code, which is very tightly packed within 0x35xxxx)
  • Implementing Expanded ROM

The randomizer does not currently work with .asm files, so you'd need to figure out what bytes would be patched over the ROM to get your feature to work, and include it in the GameWorld.get_patch() method. This goes for just about anything not covered by SMRPG Patch Builder.

Be sure to review the CONTRIBUTING.md guidelines to learn the basics of working with the randomizer code, the design philosophy behind feature development for this project, and how to credit yourself.
